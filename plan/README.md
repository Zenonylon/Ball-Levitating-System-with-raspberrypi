# 3단계 계획

전원과 팬을 먼저 안정적으로 돌리고 (1차), 센서 1개로 PID 제어를 완성한 뒤 (2차), 센서를 하나 더 붙여 공이 손 높이를 따라가게 함 (3차).
각 단계의 완료 기준을 통과해야 다음 단계로 넘어감.

```
[1차 전원 · 파이 · 팬] ──◇──▶ [2차 공 높이 센서 + PID] ──◇──▶ [3차 손 높이 센서]
                      팬 100% 에서 공이 관 위까지          목표 높이 ±2 cm
                      배터리만으로 파이 재부팅 없음         10 초 이상 유지
```

현재 상태 (2026-11-07): 1차 진행 중. 팬 단독 동작은 확인함.

## 1차: 전원, 라즈베리파이, 팬

콘센트 없이 18650 2 개만으로 라즈베리파이를 켜고, 코드로 팬 세기를 조절해서 공을 관 위까지 띄움.

### 할 일
- [x] 팬 (YDM4010S05) 이 5 V 에서 도는지, 바람 방향은 어느 쪽인지 확인
- [ ] 전원 회로: 18650 ×2 (직렬) → DC-DC 강압 모듈 (5 V) → USB-A → A-to-C 케이블 → 라즈베리파이
- [ ] 팬 회로: 같은 DC-DC 의 2×4 핀헤더 +5V / GND → 빵판 B 레일 → 팬 → 2N2222 (베이스 470 Ω, GPIO18) + 1N4148 (MB102 는 쓰지 않음, 11/07 결정)
- [ ] 배터리 쪽 GND 와 라즈베리파이 GND 연결
- [ ] 프레임에 팬 고정 (바람 나오는 면이 위, 흡입면은 받침대에서 1~2 cm 띄움) 과 관 세우기
- [ ] `src/fan_test.py` 로 팬 세기 0~100 % 조절 확인, 팬이 멈추는 값 기록
- [ ] 팬 100 % 에서 탁구공이 관 위까지 뜨는지 확인

### 완료 기준
- 배터리만 연결한 상태에서 라즈베리파이가 부팅되고 노트북에서 SSH 로 접속됨
- 팬을 0 % 에서 100 % 까지 오르내려도 라즈베리파이가 재부팅되지 않음 (`vcgencmd get_throttled` 가 `0x0`)
- 팬 100 % 에서 공이 관 위쪽까지 올라가고, 세기를 줄이면 내려옴

공이 100 % 에서도 충분히 뜨지 않으면 2차로 넘어가지 않고 여기서 해결함. 관과 팬 사이 틈을 막거나, 관을 짧게 하거나, 더 강한 팬 (예: 5015 블로워) 으로 바꾸는 방법이 있음.

## 2차: 공 높이 센서 + PID 제어

공 높이를 재는 센서 1 개를 달고, 코드에서 정한 높이에 PID 제어로 공을 멈춰 세움.

### 할 일
- [ ] HY-SRF05 #1 을 관 위 약 3 cm 지점에 아래를 향하게 고정
- [ ] 배선: Trig → GPIO23, Echo → 1 kΩ / 2 kΩ 분압 → GPIO24
- [ ] `src/sonar_test.py` 로 거리 읽기. 공을 손으로 몇 군데 높이에 두고 자로 잰 값과 비교
- [ ] 센서에서 관 바닥까지 거리를 재서 `src/config.py` 에 넣기 (공 높이 = 이 거리 − 센서가 잰 거리)
- [ ] 공이 거의 제자리에 떠 있는 팬 세기 (호버 값) 찾기
- [ ] `src/levitate.py` 로 고정 높이 (예: 관 중간) 제어. P 를 먼저 맞추고, 흔들리면 D, 목표보다 계속 낮거나 높으면 I 를 올림

### 완료 기준
- 공이 목표 높이 ±2 cm 안에서 10 초 이상 머무름
- 목표 높이를 바꾸면 공이 몇 초 안에 새 높이로 옮겨 가서 멈춤

초음파 값이 튀면 여러 번 재서 중간값을 씀.

## 3차: 손 높이 센서 추가

센서를 하나 더 달아, 손을 올리고 내리면 공이 그 높이를 따라가서 머무르게 함. 2차의 PID 는 그대로 두고 목표 높이만 손 센서 값으로 바꿈.

### 할 일
- [ ] HY-SRF05 #2 를 관에서 떨어진 곳에 위를 향하게 고정 (센서 위 40 cm 안에 다른 물건이 없게)
- [ ] 배선: Trig → GPIO17, Echo → 1 kΩ / 2 kΩ 분압 → GPIO27
- [ ] 두 센서가 서로 간섭하지 않게 번갈아 측정하는지 확인
- [ ] 손 높이 범위 (예: 센서 위 5~35 cm) 를 공 높이 범위 (관 아래~위) 에 맞춰 변환
- [ ] 손을 치우면 마지막 목표 높이를 유지하게 처리

### 완료 기준
- 손을 위아래로 움직이면 공이 따라서 움직이고, 손을 멈추면 그 높이에서 멈춤
- 손을 치워도 공이 떨어지지 않고 마지막 높이에 머무름
